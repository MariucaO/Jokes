# Jokes App

This is a simple web application that fetches dad jokes from the [icanhazdadjoke API](https://icanhazdadjoke.com) and displays them to the user. Each time the user clicks the button, a new joke is fetched and displayed along with a random button text from the list.

## Features

- Fetches jokes from the icanhazdadjoke API
- Displays jokes dynamically when the button is clicked
- Shows a loading indicator while fetching a new joke
- Randomizes button text after each click to add humor

## Tech Stack

- **HTML**
- **CSS**
- **JavaScript**
- **icanhazdadjoke API**
